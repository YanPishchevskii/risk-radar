# RiskRadar — система раннего выявления кредитного риска

Пет-проект по риск-аналитике: проверяю гипотезу о ранних сигналах дефолта, строю скоринговую модель и автоматизирую ежедневный мониторинг портфеля с алертами в Telegram и риск-заключениями от LLM.

**Стек:** Python · SQL (PostgreSQL) · n8n · LangFlow · scikit-learn · statsmodels · Streamlit · Docker

---

## Проблема

Банк присваивает клиенту статус проблемного на 31-й день просрочки. К этому моменту клиент уже не платит, и шансы договориться о реструктуризации падают. Нужен сигнал **до первой просрочки**, по поведению клиента, у которого кредитная история пока чистая.

## Решение

Система каждый день:
1. пересчитывает вероятность дефолта для каждого клиента;
2. отбирает клиентов с высоким риском;
3. генерирует по каждому короткое риск-заключение (причины + рекомендуемое действие);
4. отправляет сводку риск-менеджеру в Telegram.

---

## Гипотеза

> Среди клиентов **без единой просрочки** те, кто использует больше 80% своих кредитных лимитов (RevolvingUtilization > 0.8), уходят в дефолт (90+ дней) как минимум в 2 раза чаще остальных «чистых» клиентов.

Если гипотеза подтвердится, банк сможет связаться с клиентом раньше, чем тот получит статус проблемного на 31-й день.

- **H0:** дефолт-рейт сегмента не отличается от остальных клиентов без просрочек
- **H1:** дефолт-рейт сегмента выше
- **Метод:** z-тест для двух долей, α = 0.05

## Как запустить

1. Скачать `cs-training.csv` ([Give Me Some Credit, Kaggle](https://www.kaggle.com/c/GiveMeSomeCredit)) в `data/`
2. Поднять сервисы:
   ```bash
   docker run -d --name pg -e POSTGRES_PASSWORD=risk -e POSTGRES_DB=risk -p 5432:5432 postgres:16
   docker run -d --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n n8nio/n8n
   ```
3. Установить зависимости и загрузить данные:
   ```bash
   pip install -r requirements.txt
   python src/load.py
   psql -h localhost -U postgres -d risk -f sql/01_schema.sql
   ```
4. Запустить скоринг-API: `cd src && uvicorn api:app --port 8000`
5. Запустить LangFlow (`langflow run`) и импортировать `langflow/flow.json`
6. Импортировать `n8n/workflow.json` в n8n, указать токен Telegram-бота и URL флоу LangFlow
7. Дашборд: `streamlit run src/dashboard.py`
